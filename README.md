# Tvizle

Canlı TV ve radyo yayınlarını tarayıcı üzerinden izleyip dinlemenizi sağlayan bir web uygulaması.

## Canlı Bağlantılar

- GitHub Pages: <https://tbagriyanik.github.io/Tvizle/>
- Vercel: <https://livetvizle.vercel.app/>

## Özellikler

- Türkiye ve dünyadan popüler yasal TV & radyo kanalları (ülkeye göre gruplandırılmış)
- Türkçe / İngilizce dil desteği
- Karanlık / aydınlık tema ve renk seçimi
- Favoriler, izleme geçmişi ve arama
- Kanalları M3U listesiyle içe/dışa aktarma
- Mini oynatıcı ve genişletilebilir panel (sürükle + yeniden boyutlandır, konum kaydedilir)
- Gerçek ses frekanslarına tepki veren çok renkli görselleştirici
- Kısayol tuşları (Sayfa yukarı/aşağı ile kanal değiştirme vb.)

## Teknolojiler

React + TypeScript, Vite, Tailwind CSS v4, hls.js, Web Audio API
